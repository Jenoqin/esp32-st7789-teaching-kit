# ESP32 + ST7789 彩屏教学套件

面向课堂/自学的 ESP32 入门项目：MicroPython 固件 + **手机网页遥控彩屏**（HELLO / 模拟时钟 / 机器人 / 上海天气），并附带一套**只读硬件探测脚本**和逐屏验证过的教学讲解页。

> 所有结论都来自实机检测（esptool 直读 + REPL 实测 + 空闲引脚电气调查），不是规格书摘抄。

## 硬件

| 件 | 型号 |
|---|---|
| 主控 | ESP32-WROOM-32 开发板（CP210x 串口） |
| 屏幕 | WLK1501SPI-8P（ST7789，240×240，8 针 SPI，无触摸/无 MISO） |

接线与工作参数（SPI ≤ 20MHz、rowstart=0、必须 INVON 等）见 [显示屏接线速查.md](显示屏接线速查.md)。

## 快速开始

1. 用 Thonny 打开 `web_screen_remote.py`；
2. **先把文件顶部的 `SSID` / `PASSWORD` 改成你自己的 WiFi**（本仓库不含任何真实凭据）；
3. 按 F5 运行，屏幕会显示 IP；
4. 手机连**同一 WiFi 的同一网段**，浏览器打开屏幕上的 IP，点按钮即可。
   路由器连不上时开发板会自动开热点（YY-ESP32 / 12345678），手机连热点访问 http://192.168.4.1。

## 功能

- **HELLO 画面**：大字 HELLO, YangYang! + 爱心（8×8 自绘点阵字体，大小写齐全）
- **模拟时钟**：三针走秒 + 数字时间；NTP 自动对时，手机可手动校时
- **机器人**：基本图元绘制的机器人图案
- **上海天气**：Open-Meteo 免费接口（无需 API key），每 10 分钟自动刷新
- **息屏**：背光控制

## 安全设计

- **只允许同一网段访问**：HTTP 服务绑定板子本机 IP，且逐连接按子网掩码校验来源，跨网段/公网来源直接拒绝并记录；
- 本仓库**不含** WiFi 密码等任何真实凭据——原程序读取的凭据只存在于你本地的副本里，提交前请再次确认；
- 天气为板子主动向外的只读请求，不开放任何入站互联网控制。
